Custom Database Studio

Turn static Obsidian markdown notes into fully interactive mini-apps, databases, and custom visual dashboards.

Welcome to the Studio

Custom Database Studio is an advanced plugin for Obsidian designed to bridge the gap between static markdown notes and dynamic applications. By embedding a ```canvasview codeblock in your note, you gain access to a fully isolated runtime environment where standard HTML templates, CSS stylesheets, and JavaScript logic execute with native Obsidian integration.

⚡ Live Hot-Reloading

Instantly preview your HTML/CSS/JS edits in real-time as you type in the Studio workspace.

🧠 Smart Autocomplete

Context-aware suggestions for vault folders, tags, frontmatter keys, HTML tags, CSS properties, and `db` methods.

📦 Delta Versioning

Save multiple versions (`v0`, `v1`, etc.) of your scripts directly inside plugin data with rollback support.
