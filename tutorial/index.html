Official Guide & Reference

Custom Database Studio

Turn static Obsidian markdown notes into fully interactive mini-apps, databases, and custom visual dashboards.

1. Introduction

Custom Database Studio is an advanced plugin for Obsidian designed to bridge the gap between static markdown notes and dynamic applications. By embedding a ```canvasview codeblock in your note, you gain access to a fully isolated runtime environment where standard HTML templates, CSS stylesheets, and JavaScript logic execute with native Obsidian integration.

Key Philosophy: Everything you build inside the Studio has 100% preview parity. What you test in the live preview workspace is guaranteed to behave identically inside Reading Mode across your entire vault.

2. Architecture & File Structure

The plugin is modularly designed across dedicated TypeScript modules to maintain high performance and clean separation of concerns:

  • main.ts — Plugin lifecycle, view registration, and the markdown codeblock processor for Reading Mode with bulletproof audio/timer teardowns.
  • view.ts — The Studio Workspace editor view, managing multi-tab split panes, syntax highlighters, hot-reload triggers, and version dropdowns.
  • runtime.ts — The core db helper environment providing 18+ robust utility functions for both Studio preview and Reading Mode.
  • autocomplete.ts — An intelligent AST and vault-indexing autocomplete engine providing context-aware suggestions.
  • autocompleteWords.json — Externalized dictionaries for keywords, CSS properties, HTML tags, and object method completions (`db.*`, `app.*`).
  • modals.ts — Native Obsidian modals for naming delta versions and handling confirmations.

3. Getting Started

  1. Install and enable Custom Database Studio in your Obsidian community plugins.
  2. Create a new markdown note anywhere in your vault (e.g., Books.md).
  3. Open the Command Palette (Ctrl/Cmd + P) and type "Open Database Studio".
  4. Select your note from the top dropdown. The Studio will automatically wrap your code inside a ```canvasview codeblock wrapper.

4. The Studio Workspace

The Studio workspace features a split-screen layout with code editors on the left and a live simulation preview on the right.

Live Syntax Validation

The code editors feature custom line gutters and real-time syntax error banners:

  • JavaScript: Evaluates syntax via `new Function()` in real-time, highlighting unclosed curly braces and line numbers.
  • HTML: Validates tag nesting and unclosed tag pairs (ignoring self-closing void tags like `<img>`, `<br>`, `<input>`).
  • CSS: Tracks unmatched brace blocks.

Smart Autocomplete Engine

Pressing keys in the editor summons a smart context-aware autocomplete menu:

  • HTML Context: Suggests tags (with automatic closing tags like `<div></div>`) and attributes (`class=""`, `id=""`).
  • CSS Context: Suggests CSS properties, values, CSS variables (`--*`), and vault HTML classes/IDs.
  • JS Context: Suggests db.* helpers, Dataview methods (`dv.*`), Obsidian app.* APIs, vault folder paths ("Books"), tags ("#tag"), and local variables declared in your script buffer.

Delta Versioning System

As you iterate on your code, you can save incremental snapshots without duplicating entire files:

  • + Save as New: Creates a delta snapshot (e.g., `v1 - Update Layout`) storing only the code differences (`html`, `css`, or `js`) that changed since the parent version.
  • Rename Ver: Updates the tag label of the currently selected version.
  • Remove Last Ver: Deletes the latest snapshot with confirmation.

5. The `db` API Reference

Every canvas view script receives a global helper object named db. Below is the complete reference of available methods:

Data & Vault Methods

Method Description
db.query(source, fallback[]) Queries Dataview pages (e.g., db.query('"Books"')) with automatic fallback to native Obsidian vault folders if Dataview is disabled.
db.createNote(opts) Creates a markdown note with optional folder, title, frontmatter dictionary, and content. Automatically handles filename collision counters.
db.updateNote(fileOrPath, updaterFn) Atomically updates frontmatter properties safely using Obsidian's file manager queue.
db.increment(path, prop, by=1) Shorthand helper to increment a numeric frontmatter property by a given value.
db.toggleProp(path, prop) Shorthand helper to invert a boolean frontmatter property.
db.openNote(path) Opens a vault note in a workspace leaf.

UI & Interaction Methods

Method Description
db.renderList(selector, items, templateFn, emptyHtml) Populates a container element by mapping an array of items through a template string function.
db.bindFilter(selector, options[], onSelectFn) Generates a native button filter bar and handles active state toggling automatically.
db.modal(title, renderFn) Spawns a native-themed Obsidian popup modal with a close button and backdrop dismissal.
db.notify(msg, timeout) Triggers an Obsidian toast notification notice.
db.drag(target, onMoveFn, onEndFn) Binds touch and mouse pointer drag handlers to any element or selector.
db.onKey(keys, fn, options) Binds a scoped window keydown listener that automatically cleans up when the view unloads.
db.beep(freq, duration, type, volume) Synthesizes procedural audio using the Web Audio API with bulletproof auto-closing teardown.

Animation & State Management

Method Description
db.loop(fn) Manages a high-performance 60FPS `requestAnimationFrame` loop providing delta time and timestamp parameters.
db.timer(intervalMs, fn) Creates a managed interval timer that auto-stops when the note unloads.
db.state(initialVal, onChangeFn) Creates a reactive state store with `.val`, `.update()`, and `.subscribe()` methods.
db.storage(namespace) Provides namespaced persistent local storage (`get`, `set`, `remove`, `clear`).
db.onVaultChange(fn) Listens for vault modification events on markdown files.
db.onCleanup(fn) Registers custom teardown logic to execute when the note is closed or reloaded.

3. JavaScript Logic

// --- JS ---
container.innerHTML = htmlContent;

let books = [];
try {
  if (typeof db !== 'undefined' && db.query) {
    books = db.query('"Books"').map(b => ({
      title: b.title || b.file?.name || "Untitled",
      author: b.author || "Unknown Author",
      cover: b.cover || "https://via.placeholder.com/150x225?text=No+Cover",
      status: b.status || "Plan to Read",
      path: b.file?.path || '#'
    }));
  }
} catch (err) {}

if (books.length === 0) {
  books = [
    { title: "Atomic Habits", author: "James Clear", cover: "https://via.placeholder.com/150x225?text=Atomic+Habits", status: "Reading", path: "#" }
  ];
}

const filterBar = container.querySelector('#filter-bar-container');
const addBtn = container.querySelector('#add-book-btn');
const gridContainer = container.querySelector('#book-grid-container');

if (addBtn) {
  addBtn.onclick = async () => {
    await db.createNote({
      folder: "Books",
      title: "New Book",
      frontmatter: { title: "New Book", author: "Unknown Author", status: "Plan to Read", cover: "" },
      content: "# New Book\n\n",
      open: true
    });
  };
}

const categories = ["All", "Reading", "Completed", "Plan to Read"];
let activeCategory = "All";

function renderGrid(category) {
  if (!gridContainer) return;
  gridContainer.innerHTML = "";

  const filtered = books.filter(b => category === "All" || (b.status || "").toLowerCase().includes(category.toLowerCase()));

  if (filtered.length === 0) {
    gridContainer.innerHTML = '<div style="grid-column:1/-1;text-align:center;padding:30px;color:var(--text-muted);">No books found</div>';
    return;
  }

  for (let book of filtered) {
    const card = document.createElement('div');
    card.className = "book-card";
    card.onclick = () => {
      if (book.path !== "#" && db.openNote) db.openNote(book.path);
      else db.notify(`Clicked: ${book.title}`);
    };
    card.innerHTML = `
      <img class="book-cover" src="${book.cover}" alt="${book.title}" loading="lazy">
      <div class="book-info">
        <div class="book-title">${book.title}</div>
        <div class="book-author">${book.author}</div>
        <div class="book-status">${book.status}</div>
      </div>
    `;
    gridContainer.appendChild(card);
  }
}

if (filterBar) {
  db.bindFilter('#filter-bar-container', categories, (selected) => {
    activeCategory = selected;
    renderGrid(selected);
  });
}

renderGrid("All");

7. Troubleshooting & FAQ

Q: Why is my dashboard not updating when I modify a note?

A: Ensure your script listens to vault changes using db.onVaultChange(() => { ... }) or re-runs your query logic when appropriate.

Q: Audio keeps playing even after I switch notes. How do I fix this?

A: All audio synthesized through db.beep() or custom AudioContexts created via db.onCleanup() automatically terminate when the note unloads in Reading Mode or closes in the Studio.
