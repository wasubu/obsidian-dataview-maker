The `db` API Reference

Core Methods

Every canvas view script receives a global helper object named db. Here is the complete reference table:

Method Description
db.query(source, fallback[]) Queries Dataview pages with automatic fallback to native Obsidian vault folders.
db.createNote(opts) Creates a markdown note with folder, title, frontmatter, and content.
db.updateNote(fileOrPath, updaterFn) Atomically updates frontmatter properties safely using Obsidian's file manager queue.
db.increment(path, prop, by=1) Increments a numeric frontmatter property by a given value.
db.toggleProp(path, prop) Inverts a boolean frontmatter property.
db.renderList(selector, items, templateFn, emptyHtml) Populates a container element by mapping items through a template string function.
db.bindFilter(selector, options[], onSelectFn) Generates a button filter bar and handles active state toggling.
db.modal(title, renderFn) Spawns a native-themed Obsidian popup modal.
db.notify(msg, timeout) Triggers an Obsidian toast notification notice.
db.loop(fn) Manages a high-performance 60FPS animation loop.
