Getting Started

Installation & Setup

  1. Install and enable Custom Database Studio in your Obsidian community plugins.
  2. Create a new markdown note anywhere in your vault (e.g., Dashboard.md).
  3. Open the Command Palette (Ctrl/Cmd + P) and type "Open Database Studio".
  4. Select your note from the top dropdown. The Studio workspace will open on the right.

Codeblock Structure

Inside your markdown notes, Custom Database Studio relies on three clearly commented sections inside a ```canvasview block:

```canvasview
// --- CSS ---
.my-card {
  background: var(--background-secondary);
  padding: 16px;
  border-radius: 8px;
}

// --- HTML ---
<div class="my-card">
  <h3>Hello World</h3>
</div>

// --- JS ---
container.innerHTML = htmlContent;
db.notify("Dashboard loaded!");
```
