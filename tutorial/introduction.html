Introduction

Turn static Obsidian markdown notes into fully interactive mini-apps, databases, and custom visual dashboards.

Welcome to Custom Database Studio

Custom Database Studio is an advanced, developer-grade plugin for Obsidian designed to completely redefine how you interact with your notes. By embedding a custom ```canvasview codeblock in any markdown note, you gain access to a fully isolated, high-performance runtime environment where standard HTML5 templates, CSS3 stylesheets, and ES6+ JavaScript logic execute with native Obsidian vault integration.

⚡ Live Hot-Reloading

Instantly preview your HTML, CSS, and JS edits in real-time as you type inside the multi-pane Studio workspace.

🧠 Smart Autocomplete

Context-aware suggestions for vault folders, tags, frontmatter keys, HTML tags, CSS properties, and custom `db` methods.

📦 Delta Versioning

Save multiple incremental snapshots (`v0`, `v1`, etc.) of your scripts directly inside plugin data with robust rollback support.

The Core Philosophy & Vision

Traditional note-taking systems are fundamentally static. While standard markdown lists and tables work well for writing text, they fall short when you want to build interactive tools like personal CRMs, dynamic project trackers, visual book catalogs, habit dashboards, or custom calculators.

While tools like Dataview allow you to query notes into tables and lists, they lack user interactivity, responsive card layouts, custom animations, and state management. Custom Database Studio solves this by giving you a complete front-end development workspace right inside your vault, powered by your own vault notes as the database.

  • Zero Build Tools: No external Node.js servers, Webpack configurations, or compilation steps required. Everything runs natively inside Obsidian.
  • Secure & Sandboxed: Scripts execute within a controlled DOM container (`container`), ensuring your dashboard never interferes with other notes or plugins.
  • Vault as a Database: Every note in your vault is a potential database record, complete with frontmatter properties, tags, and links.

Under the Hood: Architecture Overview

Custom Database Studio is engineered with a robust, multi-layered architecture ensuring that code tested in the Studio workspace behaves 100% identically when rendered in Reading Mode across your vault:

  • The Studio View (`view.ts`): A dedicated Obsidian workspace leaf providing split-screen editors for HTML, CSS, and JS, featuring syntax highlighting, error banners, and code linting.
  • The Shared Runtime (`runtime.ts`): A universal helper engine that injects the db API suite into both the live Studio simulation preview and Reading Mode codeblock processors.
  • Bulletproof Teardown: Automatically cleans up lingering animation loops (`requestAnimationFrame`), active timers, keyboard event listeners, and Web Audio contexts the moment you close a note or switch tabs, preventing memory leaks and audio bleeding.

Glossary of Key Terms

As you explore this documentation, you will encounter a few recurring technical terms:

  • CanvasView — The custom markdown codeblock identifier (```canvasview) parsed by the plugin.
  • db API — The global utility object providing 18+ methods for vault querying, note creation, UI rendering, modals, and animations.
  • Delta Versioning — A memory-efficient snapshot system that records only the changed lines between code iterations rather than duplicating entire files.
  • Scoped Selectors ($ / $$) — Container-scoped query selectors that prevent your dashboard CSS and JS from affecting the rest of Obsidian.
