High-DPI Canvas Setup (`db.canvas`)

Standard HTML5 canvases look blurry on Retina and high-DPI displays unless scaled correctly. db.canvas() automatically calculates device pixel ratios, scales the 2D context, and sets logical canvas dimensions:

// HTML: 
const setup = db.canvas('#myCanvas');

if (setup) {
  const { canvas, ctx, width, height, clear } = setup;
  
  // Clear canvas with background color or transparent
  clear('#1e1e2e');

  // Draw sharp graphics
  ctx.fillStyle = '#cba6f7';
  ctx.fillRect(20, 20, 80, 80);
}

Pointer Drag Handler (`db.drag`)

Easily make UI elements draggable using pointer events that seamlessly support both mouse and touch input:

// HTML: 
Drag Me

db.drag('#draggable-box', (dx, dy, e) => {
  const box = $('#draggable-box');
  box.style.transform = `translate(${dx}px, ${dy}px)`;
}, () => {
  db.notify("Drag released!");
});

Scoped Keyboard Listeners (`db.onKey` & `db.onKeyUp`)

Listen for specific keyboard shortcuts, key presses, and key releases scoped to your view (with automatic unbinding when switching tabs or closing the note):

// Track smooth movement by listening to both keydown and keyup
let isMovingUp = false;

db.onKey(['ArrowUp', 'w', 'W'], (e) => {
  isMovingUp = true;
});

db.onKeyUp(['ArrowUp', 'w', 'W'], (e) => {
  isMovingUp = false;
});

// Listen for Spacebar press
db.onKey(' ', (e) => {
  e.preventDefault();
  db.notify("Spacebar pressed!");
});

Reactive State Stores (`db.state`)

The db.state() helper creates a reactive state container with built-in subscription handling:

const counter = db.state(0, (newValue) => {
  console.log('State changed to:', newValue);
});

counter.val = 5; // Triggers change listener
counter.update(prev => prev + 1); // Increments to 6

Persistent Namespaced Storage (`db.storage`)

Save local dashboard data that survives Obsidian restarts using namespaced local storage:

const store = db.storage('book_dashboard');

store.set('view_mode', 'grid');
const mode = store.get('view_mode', 'list'); // returns 'grid'

store.remove('view_mode');
store.clear(); // Clears all keys starting with 'cds_book_dashboard_'
