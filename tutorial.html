Custom Database Studio

Transform your Obsidian notes into stunning, interactive mini-apps, widgets, and databases with live HTML, CSS, and JS execution.

✨ Overview

Custom Database Studio is an all-in-one development studio built directly inside Obsidian. It allows you to write custom user interfaces using standard HTML, CSS, and JavaScript, query your vault notes seamlessly, and render them in Reading Mode using the custom ```canvasview codeblock.

⚡ Live Hot-Reloading

Instantly preview your HTML/CSS/JS edits in real-time as you type in the Studio workspace.

🧠 Smart Autocomplete

Context-aware suggestions for vault folders, tags, frontmatter keys, HTML tags, CSS properties, and `db` methods.

📦 Delta Versioning

Save multiple versions (`v0`, `v1`, etc.) of your scripts directly inside plugin data with rollback support.

🚀 Getting Started

  1. Open the command palette (Ctrl/Cmd + P) and run "Open Database Studio", or click the template icon in your left ribbon.
  2. Create or select an existing Markdown note that contains a ```canvasview block.
  3. Use the HTML, CSS, and JS Logic tabs to build your interface.
  4. Click 💾 Update Note to save your code back into the markdown file.

🛠️ The `db` Helper API

Your JavaScript code has access to a powerful global object named db designed specifically for Obsidian vaults:

1. Vault & Dataview Querying

// Queries pages in the "Books" folder or matching criteria
const books = db.query('"Books"');

2. Frontmatter & Note Automation

// Increment a frontmatter property atomically
await db.increment('Notes/Project.md', 'completedTasks', 1);

// Toggle a boolean frontmatter property
await db.toggleProp('Notes/Settings.md', 'darkMode');

// Create a new note with frontmatter and open it
await db.createNote({
  folder: 'Tasks',
  title: 'New Task',
  frontmatter: { status: 'todo', priority: 'high' },
  content: '# Task Details\n\n',
  open: true
});

3. UI Helpers & Modals

// Display a native Obsidian notice toast
db.notify('Operation successful!');

// Open a native-themed DOM modal
db.modal('Settings', (bodyEl, close) => {
  bodyEl.innerHTML = '
Hello from modal!
';
});

// Play procedural audio feedback
db.beep(440, 0.1, 'sine', 0.1);

4. Animation Loops & Timers

// 60FPS High-Performance Animation Loop
const anim = db.loop((delta, time) => {
  // animation frame logic here
});
anim.start();

// Managed timer
const timer = db.timer(1000, () => {
  console.log('Ticked every 1 second');
});
timer.start();

📦 Codeblock Structure

In your markdown files, ```canvasview blocks are structured into three clearly commented sections so the Studio can parse and edit them independently:

```canvasview
// --- CSS ---
.my-card {
  background: var(--background-secondary);
  padding: 12px;
  border-radius: 8px;
}

// --- HTML ---
<div class="my-card">
  <h3>Hello World< /h3>
< /div>

// --- JS ---
container.innerHTML = htmlContent;
db.notify("CanvasView loaded successfully!");
```

🎨 Obsidian Theme Integration

Custom Database Studio automatically inherits Obsidian's native interface variables. Always use CSS variables in your stylesheets so your dashboards adapt seamlessly to light and dark modes:

  • var(--background-primary) — Main background color
  • var(--background-secondary) — Card and sidebar background
  • var(--background-modifier-border) — Clean borders
  • var(--interactive-accent) — Obsidian accent color for buttons and active tabs
  • var(--text-normal) — Primary text color
  • var(--text-muted) — Subtitles and secondary text
